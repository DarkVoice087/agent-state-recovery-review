# Пример восстановления состояния для ревью

Самостоятельный пример Python без сторонних зависимостей. Единственное состояние —
счётчик, входы — выдуманные целые числа. История репозитория новая; производственных
модулей, данных и ключей здесь нет.

```sh
python -B -m unittest discover -v
python -B demo.py
```

Журнал и checkpoint сохраняются одним блоком, разрешённые хеши — отдельно.
До публикации записывается намерение со старым и новым хешем. После потери
подтверждения допускается только заранее разрешённая версия; неизвестные данные
сохраняют намерение открытым. Синтетические тесты включают аварийные завершения
дочерних процессов, порчу файлов и повтор восстановления.

Нужен review окон сбоя, порядка блокировок, защиты от одновременного отката
двух файлов и требований к долговечности metadata на Windows. Отключение питания
не аттестовано. Настройка ACL, внешний монотонный якорь, реальные внешние действия
и производственное применение не входят в пример. Полные границы — в README.md.

Лицензия на повторное использование пока не выбрана; репозиторий опубликован
для обсуждения. Публикуйте в issues только синтетические примеры.
